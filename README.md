# כותרות הטק · לוח גילוי

פורטל כותרות אישי בעברית ובכיווניות RTL. לוח כהה, כרטיסים בגוונים קבועים לפי מדור ומשבצת בולטת ל״הרחבת אופקים״. הכותרות מפנות ישירות למקור. גוף הכתבות נשאר באתרי המקורות.

## הרצה מקומית

נדרש Node.js בגרסה 22.15 ומעלה ו־npm. מצב הדוגמה פועל מיד עם התקנת התלויות. הכרטיסים בו מסומנים כנתוני דוגמה, והתאריך המצוין הוא תאריך יצירת מהדורת הדוגמה המקומית.

```sh
npm ci
npm run dev
```

פתחו את `http://localhost:3000`. אפשר להגדיר `PORT` בקובץ `.env`. לעריכה עם טעינה חמה, הפעילו `npm start` ואת `npm run dev:client` בשני חלונות ופתחו את הכתובת שמדפיס Vite.

לבניית גרסת הפעלה על אותו מחשב

```sh
npm run build
npm run start:production
```

## מקורות חיים ותזמון

1. העתיקו את `.env.example` ל־`.env` והגדירו `NEWS_MODE=live`.
2. בחרו דרך להפקת כותרת בעברית. אפשר להגדיר `TRANSLATION_BASE_URL` ו־`TRANSLATION_MODEL` עבור שירות תואם OpenAI עם `/chat/completions`. שירות מקומי כגון Ollama זמין ב־`http://127.0.0.1:11434/v1` ויכול להשתמש במודל מותקן שתומך בעברית. הוסיפו `TRANSLATION_API_KEY` רק אם השירות דורש מפתח. אפשר גם להגדיר `EDITION_FILE` ולהזין מהדורה מובנית עם כותרות עבריות מוכנות.
3. הפעילו את שרת הפורטל והשאירו אותו רץ. במצב חי הוא אוסף בעת עלייה וגם ב־08:00, ב־14:00 וב־20:00 לפי `Asia/Jerusalem`, כולל מעבר בין שעון קיץ לשעון חורף. תהליך מקומי שרץ ברציפות יכול להריץ את המתזמן.

ברירת המחדל משתמשת ב־RSS ממקורות כמו OpenAI, NVIDIA, Cornell Tech, AlleyWatch, South China Morning Post, TechCrunch ומקורות מדע ותרבות. ניתן להחליף את הרשימה בעזרת `SOURCES_FILE` שמצביע על מערך JSON. לכל מקור דרושים `name` ו־`url`. אפשר להגדיר `region` כאחד מ־`קליפורניה`, `מדינת ניו יורק`, `סין`, ו־`category` כאחד מ־`ai`, `chips`, `market`, `policy`, `discover`. הגדירו אזור ברירת מחדל רק למקור שממוקד באזור הזה. לשילוב מהדורה מובנית עם RSS, הגדירו גם `EDITION_FILE` וגם `SOURCES_FILE`.

```json
[
  {
    "name": "Cornell Tech",
    "url": "https://tech.cornell.edu/feed/",
    "region": "מדינת ניו יורק"
  },
  {
    "name": "Ars Technica",
    "url": "https://arstechnica.com/science/feed/",
    "category": "discover"
  }
]
```

מהדורה מובנית היא מערך JSON. בכל רשומה נדרשים `url`, `title`, `titleHe`, `source`, `category`, `region`, מערך `topics` לפי סדר חשיבות ו־`publishedAt` בתקן ISO 8601. השתמשו באותו `eventId` לכתבות המתארות את אותו אירוע. כללו `heUrl` עם `heVerified: true` רק אחרי שבדקתם שזהו תרגום רשמי מלא של הכתבה. הוסיפו `popularity` עם `popularityVerified: true` רק עבור אות ציבורי שאומת. הזנת הקובץ מתאימה ליצוא עתידי ממקור החדשות הקיים. הפורטל פועל באופן עצמאי מאוטומציית המייל.

מתרגם הכותרות מקבל רק כותרות מקור ומזהים. כותרות בלי עברית זמינה נשארות מחוץ למהדורה. תיאור RSS משמש לסיווג בזמן האיסוף ואינו נשמר במסד. ברירת המחדל מאפשרת שבעה ימים למדורים הרגילים ו־21 ימים להרחבת אופקים. במקרה כשל, האיסוף נמשך עם המקורות הזמינים והרשומות הקיימות נשמרות. הפקודה `npm run check:feeds` מציגה כמה רשומות נקראו מכּל מקור וכמה היו עדכניות ומתאימות. היא לא משתמשת במתרגם.

### אחסון והעדפות

- `DATABASE_PATH` קובע את נתיב קובץ SQLite. בהפעלה אצל ספק אחסון, בחרו נתיב על נפח מתמשך. המצבים חיים ודוגמה משתמשים כברירת מחדל בקבצים נפרדים.
- עוגייה עם מזהה אקראי מקשרת את הדפדפן להעדפות, לקטגוריות, להיסטוריית החשיפות ולפעולת הביטול האחרונה ב־SQLite. שימור בין ביקורים עובד באותו פרופיל דפדפן. ה־MVP מיועד לשימוש אישי. שימוש בחשבון משותף בין מכשירים דורש הוספת התחברות.
- פלוס נותן עדיפות לתת־נושא זהה או לתגיות משותפות באותה קטגוריה. מינוס מחפש תת־נושא אחר ומעדיף את הקטגוריה הנוכחית. כשהמלאי החדש נגמר, הפורטל מחזיר בסבב כותרות ותיקות שפחות לאחרונה הופיעו. פריסת הלוח משאירה כותרת חלופית מכל מדור כשיש מספיק ידיעות. אם אותה משבצת מחזיקה בידיעה היחידה הזמינה למדור, הידיעה נשארת גלויה עד שתהיה חלופה.
- משבצת גילוי בוחרת ממלאי הגילוי לפי טריות ומגוון נושאים ומקורות. כשיש מלאי מתאים, מסך מלא מקצה ארבע מתוך עשרים משבצות לגילוי. כרטיסים במצב חי מציגים תאריך פרסום כדי להבחין בכתבות מהארכיון.
- מזהה פעולה ומזהה הכתבה הצפויה מונעים הצבעה כפולה. ביטול משחזר את המשבצת ואת משקל ההעדפה הקודם. היסטוריית החשיפות נשמרת גם אחרי ביטול או איפוס העדפות. כפילויות בין מקורות מסוננות לפי כתובת קנונית, מזהה אירוע ודמיון בין כותרות קרובות בזמן. הזנות חיות משתמשות בכללי התאמה, ולכן מהדורה ערוכה יכולה לשפר את האיחוד בעזרת `eventId` מאומת.
- קטגוריות אישיות מקבלות תג קבוע ומתאימות לפי הכותרת, מילות מפתח ומילון נרדפים עברי–אנגלי. האיסוף הבא משתמש גם בשמות הקטגוריות השמורים. כתבה מוצגת במשבצת אחת, גם אם היא מתאימה למספר מדורים.

## בדיקות

```sh
npm test
npm run typecheck
npm run check:feeds
```

בדיקות האוטומציה מכסות החלפות וביטול, קטגוריות דו־לשוניות, מניעת כפילות, עמידות SQLite, קליטת מהדורה מובנית וכשל חלקי של מקורות. בסימולציות, 240 הצבעות עוקבות משאירות את חמשת המדורים מלאים גם אחרי שמלאי הידיעות החדשות נגמר. 20 הצבעות בתחום אחד ועוד 20 החלפות במשבצת גילוי בודקות את מספר משבצות הגילוי ואת הגיוון בנושא ובמקור. בדיקת המתרגם משתמשת בשירות מדומה מקומי. להפעלת עדכוני RSS בעברית בחרו שירות תרגום משלכם או ספקו קובץ מהדורה עם כותרות בעברית.
